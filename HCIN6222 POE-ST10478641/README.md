# CampusPark — Smart School Parking Prototype

## Run the prototype
1. Extract the ZIP file.
2. Open `index.html` in a modern browser.
3. Select bays, filter Area A/Area B, or press Refresh to simulate a sensor update.
4. Resize the browser to see the responsive layout.

No installation or build tools are required.

## Files
- `index.html`: semantic website structure
- `css/style.css`: styling and responsive layout
- `js/script.js`: interactive bays, filtering, status counts and simulated refresh

## Important limitation
This is a front-end prototype. Parking data is simulated; it does not connect to physical magnetic-pulse sensors, a database or a server. Usage statistics are illustrative examples, not actual campus data.

## Accessibility features demonstrated
- Skip link and semantic page regions
- Keyboard-operable controls with visible focus
- Bay labels and status text as well as colour
- ARIA labels, pressed states and live status messages
- Responsive layout and reduced-motion preference support
